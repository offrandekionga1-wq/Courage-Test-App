Orientation de l'écran

Par-dessus les autres applis

L'avatar reste affiché dans une fenêtre flottante pendant que tu utilises une autre appli ou un jeu. Avec le fond « Aucun », seul l'avatar apparaît.

Dans la fenêtre : glisse pour la déplacer, pince pour la redimensionner, touche deux fois pour afficher les boutons (taille, retour à l'appli, fermer). Revenir dans Avatar Live ferme la fenêtre.

Sur l'écran : glisse un doigt pour déplacer l'avatar, pince pour zoomer. En mode live, touche deux fois l'écran pour faire revenir l'interface.
